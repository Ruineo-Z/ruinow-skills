# 封面创作

## 目标

封面首先是一张好看的整身穿搭照片：人物、服装、披肩、环境和拍摄关系共同成立。披肩需要看得出，但不为了展示披肩把人物拍成商品目录或刻意摆拍。

默认制作 3:4 竖版封面，默认不加标题、花字、贴纸或平台元素。需要文字时参见下文「封面文字」一节。

## 推导顺序

### 0. 确认人物参考

开始制作封面前，必须有独立的人物参考图：

- 用户提供人物图时，按 [人物参考](model-reference.md) 处理。
- 用户没有提供人物图时，先生成并保存 `model.png`，再继续封面。
- `model.png` 只提供人物身份，不固定表情、视线、脸部朝向、服装、环境或构图。

### 1. 读取商品图

商品图可以是纯商品展示图，也可以是披肩穿在模特身上的上身图。无论哪种，读取范围都只有披肩：

- 颜色、图案、边缘、轮廓和结构；
- 图中可见的覆盖范围、垂落、褶皱和受力关系；
- 现实中可以成立的穿戴方式。

上身图中的模特、内搭、姿势、表情、背景、机位和构图不作为封面模板。多张商品图用于补充不同角度；只有正面时，背面可以按结构和穿戴关系推断。

### 2. 确认场景参考

封面使用用户提供的真实环境或对标参考图。用户没有提供场景参考时，先索取一张；没有可用场景参考时，不直接凭文字生成背景。

场景图只提供地点环境、可辨认的空间结构、现场光线和生活痕迹。图中有人物时，不继承其身份、服装、姿势、表情或商品。尽量保留地点的建筑、地形、道路、水岸或植被特征；人物位置、机位、取景、光线和不决定地点识别的次要元素可以重新设计。

### 3. 设计整身穿搭和环境

根据披肩特征决定内搭、下装、鞋包、发型和适合的使用场景，再选择人物在环境中的位置。环境需要有具体的生活痕迹和空间关系，不默认干净、整齐、无人或像影棚一样完整。

根据披肩特征决定内搭、下装、鞋包、发型和适合的使用场景，再把人物放进已选的真实场景。场景图提供背景，不决定人物穿搭或姿势。整套笔记不要求所有图片使用同一地点；候选场景可以分别来自同一地区的古镇、湖岸、麦田、山路等环境。

### 4. 设计一个真实瞬间

先确定人物正在做什么，再从这个行为决定表情、视线、脸部朝向、身体方向、手的位置和披肩状态。不能让人物为了让镜头看清披肩而站好、摊开披肩或固定看向镜头。

### 5. 设计光线和构图

最后决定光源方向、阴影后果、拍摄者位置、机位高低、人物在画面中的位置、人物占比、留白和景别。人物比例是整张照片的结果，不默认居中、全身刚好装满，也不默认近距离展示披肩。

第一视觉重点是整身穿搭与人物和环境的关系。披肩可以清楚出现，也可以被动作或环境部分遮挡、从侧面出现或自然垂落。

### 6. 生成前检查

- `model.png` 已存在，并且提示词没有把它的表情或脸部朝向写成固定模板；
- 商品图只承担披肩外观和可见上身效果；
- 场景参考图来自用户提供，提示词明确它只承担背景环境和地点结构；
- 场景中的建筑、地形、道路、水岸或植被等地点特征仍然可辨认；
- 穿搭、环境、人物行为、披肩状态和机位在现实中能够同时成立；
- 画面即使不靠近披肩，整身穿搭和环境关系仍然好看；
- 环境保留了具体生活痕迹，人物没有被设计成展示商品的姿势；
- 光线、构图和人物状态相互配合，而不是分别堆叠要求。

## 封面文字

默认不加。穿戴类商品的点击理由来自画面本身。用户明确要求文字时，只放一个重点，放在空白处或主体边缘，不遮挡人物和披肩。图片模型生成中文不稳定时，优先让模型留出排版位置，文字由用户在上传前添加；确实让模型生成文字时，逐字核对。

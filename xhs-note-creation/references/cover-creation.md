# 封面创作

## 目标

封面要先成为一张符合本篇整体审美、值得目标读者停留的图片。商品应自然融入搭配或使用情境；露出程度依内容需要决定，不为了展示而破坏整体关系。

默认制作 3:4 竖版封面，不加标题、花字、贴纸或平台元素。用户要求文字时再设计排版。

## 推导

### 1. 确认内容与审美

沿用已确认的读者、主题和整体审美。若尚未确定，只补问会改变封面设计的关键点，不要求完整填写品牌或人物设定。

### 2. 读取商品和参考素材

按商品品类提取图像和用户资料能支持的特征，区分客观商品事实、画面可见信息和待创作的搭配方案。参考图按需要使用：商品图帮助保持外观；人物图用于需要固定身份时；场景图用于复现具体地点或关系时。商品上身图中的人物、背景和穿法是否参考，应根据用户目标决定。

### 3. 设计整体关系

先确定商品与服装、人物气质、配件或使用空间是否协调，再确定呈现方式。穿戴商品考虑颜色、比例、材质观感和层次；其他商品考虑用途、尺度及与周围物件的关系。选择环境及其中长期使用痕迹和当下活动的少量线索。

### 4. 安排人物、动作和镜头

设计一个与环境和商品用途相符的拍摄状态。人物可以摆出有设计的姿态，不必像随手抓拍；动作、表情和商品状态应舒服并符合物理关系。之后确定光线、焦点与景深、摄影者位置、机位、构图和商品可见程度。

## 生成前检查

- 封面的整体审美是否清楚，商品是否与服装或使用场景协调？
- 内容主题和商品关系是否一眼可理解，但没有变成硬性推销画面？
- 人物状态、环境线索和商品状态是否彼此相容？
- 景深与虚化能否由焦点、镜头和空间距离解释？
- 需要保持的商品外观、人物身份或具体地点是否配有恰当参考图？没有必要的参考不强制索取。

## 封面文字

默认不加。用户明确要求文字时，只突出一个重点，避免遮挡商品和画面主体。图片模型生成中文不稳定时，优先留出版面，由用户在上传前添加；让模型生成文字时逐字核对。

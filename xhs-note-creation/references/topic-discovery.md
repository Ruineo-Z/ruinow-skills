# 选题生成

## 职责与时机

当用户不知道这一篇写什么、需要一批候选方向，或想把一个模糊想法变成能写的选题时使用。这里产出的是**内容方向**，不是标题或正文；方向确定后交给 [创作准备与笔记方向](note-direction.md) 锁定时效与人群，再进入图片和文案。

用户已有明确想法时直接沿用，不走这套流程。

## 先回答三个问题

一个方向成立，需要同时答出下面三件事。答不出就先补，不要动笔。

| 问题 | 要答到什么程度 |
|---|---|
| 写给谁 | 具体到一个能对上号的人群，不是"女生"这类全覆盖说法 |
| 她在意什么 | 一个具体问题、穿搭期待、风格向往或场景兴趣；不必强行设定痛点 |
| 她能带走什么 | 看完之后得到的灵感、建议、判断或审美感受，而不是店家想卖什么 |

第三条最容易自欺。主题要先对读者有用或有吸引力；商品可以自然参与内容，但不能只把商品卖点换一种说法，就当成读者价值。

## 把自嗨改成读者视角

下笔前用三条校准：

- **读者视角**：先想读者会对什么感兴趣、想得到什么，再看商品是否适合进入内容。
- **内容价值**：可以是可执行的搭配建议，也可以是值得参考的风格与场景灵感；不要求每篇都解决问题或介绍产品特点。
- **叠加场景**：同一个人群在不同场景里的关注点可能不同，拆开后可以形成不同方向；不要为了拆题凭空制造问题。

## 九宫格裂变

想不到方向时用这个办法。机械，但有效，而且不需要任何后台数据。

```
画三个 3×3 的格子，中心格分别写 人群 / 场景 / 关注点，周围八格填满
→ 三类各取一格组合，就是一个候选方向
```

以穿戴类商品为例：

| 中心 | 周围八格可以填 |
|---|---|
| 人群 | 学生、通勤者、旅行爱好者、居家者、送礼者等，按商品调整 |
| 场景 | 通勤、旅行、聚会、居家、节日等，按商品调整 |
| 关注点 | 不会搭配、选择困难、使用不便、希望呈现某种风格、寻找某种场景灵感等，按内容调整 |

组合示例：

- 通勤者 × 上班穿搭 × 不会搭配 → 一套省心的通勤搭配思路
- 旅行爱好者 × 旅拍 × 画面层次单一 → 适合旅行照片的叠穿建议
- 送礼者 × 朋友生日 × 不知道怎么选 → 按对方日常风格挑选礼物的思路

一个格子填满就能裂变出几十个方向。想到新的人群或场景时回来补格子。

## 五个方向模板

九宫格给出的是"谁在什么场景遇到什么"，下面五个模板把它翻成一个更具体的内容角度。

| 模板 | 读者为什么看 | 穿戴类示例 |
|---|---|---|
| 实用 | 想解决一个具体问题 | 长外套怎么叠穿更有层次 |
| 共鸣 | 觉得"这说的就是我" | 衣柜里颜色不少，出门还是觉得不好搭 |
| 认知 | 想知道点实用判断 | 选日常包，先看哪些细节更适合通勤 |
| 反常识 | 与预期不一样，想看看 | 浅色不一定难搭，关键看整体配色 |
| 热点与节令 | 正在关心这件事 | 降温后通勤，怎么穿得轻便又有层次 |

**热点与节令要加一道约束**：用之前先确认这个话题的人群和读者是同一批人。借了关注度但来的人不关心配饰，就只是虚假热闹。没有共同人群时宁可不用，也不要为了时效硬加主题。

## 使用者与买单的人

有些商品是买给自己用，有些是买来送人。这两种情况的读者不是同一批人，内容要对着**实际掏钱的那个人**写。

当商品既可自用也常被送礼时，两个方向都可能成立，但要在开始时选定一个：

- **送给别人** → 读者是挑礼物的人，内容围绕送谁、什么场合送、怎么显得有心思。
- **买给自己** → 读者是使用者，内容围绕适用场景、怎么搭或怎么用。

选定之后再往下推导。不要在正文里两边都顾，那样两边都不像。

## 选题来源

方向不够时按当前能做到的往下取：

- **搜索框联想**：用"人群 + 场景"而不是品类词去搜，看下拉提示里读者自己怎么描述需求。
- **评论区与私信**：用户反复问的问题，本身就是一整个方向。
- **同行的对标内容**：看哪些方向在同类账号上被反复做（怎么找、怎么拆见 [对标分析](benchmark-analysis.md)）。
- **季节与节日**：只在和商品确实相关时用。具体天气和活动信息没有依据就不写成已核实事实。
- **自己发过的内容**：表现好的方向可以换个角度再做一次，不是重复发同一篇。

## 输出

给 3～5 个候选方向，每个写清：写给谁、什么场景或关注点、她能得到什么、商品是否以及如何自然参与、画面准备怎么支持。说明依据来自哪里（用户提供的信息、可见的评论问题，还是我们的推测）。

推测的方向要标明是推测，不冒充已验证的用户需求。用户选定后再进入下一环节，不提前展开标题和正文。

## 边界

- 不从商品或图片的偶然细节反推读者痛点，也不把商品硬写成某个问题的解决方案。依据不足时，可以把内容方向作为创作建议提出，由用户判断是否适合账号。
- 不承诺流量、排名或成交。方向好只说明值得写，不等于会火。
- 不为让方向好听而夸大商品能力。商品能支持什么，以商品图和用户提供的资料为准。

# 标题创作与修改

## 职责

与封面一起吸引可能喜欢商品的读者点击，同时说清内容主题，方便有明确需求的人找到这一篇。标题提供相关信号，不承诺流量或排名。

## 先确定一句话重点

先用一句话说清“这篇写给谁、在什么场景下、要解决什么问题或看什么搭配”。标题只承担一个主要点击理由：让读者看到与自己有关的内容，或想知道一个具体的搭配结果。不要把多个卖点、多个场景和多个承诺都塞进同一个标题。

标题应当脱离正文也能看懂；正文负责补充细节，不负责替标题解释关键名词。

## 槽位清单

先从下面的清单找出这一篇确实有依据的元素，再组织成一句话。清单是检查信息是否齐全，不是要求每个标题都把所有元素写进去。

| 槽位 | 内容 | 例子 |
|---|---|---|
| 人群 | 读者的自我描述 | 小个子女生、微胖女生、上班族、学生党 |
| 场景 | 在哪、什么时候 | 通勤、旅行、草原旅拍、约会、秋天 |
| 需求 | 想解决什么 | 不会配色、想要温柔感、不想费心搭配、拍照好看 |
| 风格 | 想要的气质 | 法式、文艺、温柔、慵懒、极简 |
| 品类 | 什么商品 | 按当前商品填写 |
| 地域 | 只在确实相关时 | 一般用不上 |
| 具体亮点 | 画面或资料能支持的搭配或使用结果 | 颜色组合、叠穿层次、空间收纳 |

规则：

- 选 **2～3 个**槽位，不是越多越好。
- **品类**不是每篇必带。若标题从明确的关联需求切入，正文开头、配图和标签应尽快让读者理解商品与主题的关系；若不写品类会让标题对象不清，或商品本身就是主要搜索意图，则直接写明商品。
- **至少 1 个读者相关槽**（人群 / 场景 / 需求），否则就是泛标题，谁都不觉得与自己有关。
- **具体亮点**可以替代风格词，但不要和同义的搭配、效果词重复堆叠。
- 人群和场景词必须来自已确认的目标读者和真实内容，不编年龄、身材、地域。关联需求词也必须是商品和配图能够回应的真实使用场景，不能只因为看起来搜索量大就套用。
- 效果承诺（显瘦、显高、保暖）必须有配图或用户提供的资料支撑。
- 不编造商品事实、客观数据或顾客评价。创作型分享口吻可按用户要求设计，不将其冒充为可核实的顾客评价或经营数据。

## 推导

以已确认的笔记方向、目标读者和可见事实清单为基础：

1. 从清单里挑出最有用的 2～3 个槽位，并确定一个主要点击理由。
2. 把读者最关心、也最能区分这篇内容的信息前置；不要为了前置关键词牺牲句子通顺。
3. 判断商品词的放置位置：
   - **商品明确型**：商品是主要搜索对象，或标题不写就无法判断内容，直接写明商品。
   - **需求优先型**：读者关心的是场景、搭配或使用需求，标题可以先写需求和结果，不强行加入商品名；正文、图片和标签应让商品关系清楚。
4. 组织成读者能一眼看懂的句子，不是把槽位词直接拼起来。
5. 朗读一遍，删掉不影响理解的形容词、重复的商品名和空泛的赞美。

例如配图确实展示浅色披肩搭配深蓝长裙的旅行穿搭时：

- 场景 + 品类 + 具体亮点：`旅行穿搭，浅色披肩配蓝裙子`
- 人群 + 场景 + 品类：`去旅行怎么搭披肩更轻松`
- 场景 + 搭配结果（需求优先型）：`旅行穿搭这样叠一层更有层次`

不用每次写年龄、身高、地域或问句；也不为凑槽位硬塞信息。情绪和观点可以保留，但要落在具体内容上，不只重复“好看”。

表达保持简短，默认 20 字以内，最终以发布端限制为准。标点和 emoji 服务语气，不是必须。

## 候选与推荐

同一确认方向下给三个候选，围绕同一具体需求，表达侧重可以不同，但不偷偷换主方向；附一句简短理由并推荐一个。三个候选都应具体、自然、有点击理由，不机械分成“情绪版 / 搜索版 / 种草版”。

三个候选至少在句子组织或信息前后顺序上有区别，不能只替换一两个形容词。候选可以分别测试商品明确型和需求优先型，但不能让其中一个脱离本篇真实需求。推荐时说明它为什么比另外两个更清楚、更贴合图片或更像目标读者会说的话，不把推荐说成流量预测。

给出推荐标题时可同时给一版正文，正文兑现同一内容重点。用户只要求一个标题、只改指定标题或已有选定标题时，按请求处理，不额外产出三个候选。

## 检查与修改

- 读者能否知道具体内容、判断是否与自己有关，并获得点击理由？
- 是否覆盖 2～3 个槽位，且有至少 1 个读者相关槽？
- 商品、场景、人群和关联需求词是否有依据且读起来通顺？
- 是否只有一个主要承诺？如果标题没有写商品名，正文开头、配图和标签是否会及时补足商品关系？
- 图片和正文是否支持标题的承诺？
- 是否删掉了空泛赞美、关键词堆叠和未经证实的商品效果或客观信息？
- 是否保留用户认可的主题和口吻，仅修改反馈涉及的部分？

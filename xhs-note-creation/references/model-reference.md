# 人物参考

## 适用时机

只有需要在多张图中保持同一人物身份，或用户明确要求固定人物时，才准备独立人物参考。不同笔记之间不要求沿用同一人物。

- 用户提供了人物图时，先确认它作为本篇人物参考；不要未经同意换人。
- 用户没有提供人物图、但任务确实需要身份一致时，可先生成 `model.png`；不需要保持身份时直接按本张内容设计人物。
- 人物参考只负责身份和比例：脸型、五官关系、发型、发色、年龄感、体型和可辨认的整体外貌。这些属性只在当前笔记内保持一致，下一篇笔记可以重新设计。
- 人物参考不负责表情、视线、脸部朝向、姿势、服装、商品、环境、机位或构图。
- 人物参考使用三个视图：正面、约 45 度角和侧面。三个视图属于同一个人，但表情、视线和头部朝向不必完全相同，避免变成三张复制脸。
- 人物参考使用普通生活光线和不强调商品的简单衣着，避免它本身变成一张需要复制的成片。
- 皮肤使用自然半哑光效果，保留轻微肤色变化和真实纹理；避免额头、鼻梁和面颊出现油腻高光、湿润妆面、塑料皮肤或过度磨皮。

## 生成方式

人物参考不传商品图，也不传封面或对标图。用 [生图脚本](../scripts/generate.mjs) 保存为笔记目录中的 `model.png` 和 `model.md`。`model.png` 是一张包含三个视图的身份参考图，不是最终笔记配图：

```bash
node <skill目录>/scripts/generate.mjs \
  --prompt-file <笔记目录>/model.prompt.json \
  --dir <笔记目录> --name model
```

提示词只描述身份参考，不设计最终穿搭：

```json
{
  "type": "小红书人物身份参考",
  "goal": "为当前这篇笔记建立可辨认但不锁定表情和拍摄状态的人物身份；下一篇笔记可以重新设计模特",
  "subject": {
    "person": "年龄段、脸型、五官关系、发型和发色等可辨认特征",
    "hair_and_makeup": "简单、稳定、不过度修饰的发型和妆容",
    "pose": "同一张参考图包含正面、约45度角和侧面三个视图；三个视图保持同一人的脸型、五官、发型和体型，但表情和视线有轻微自然变化"
  },
  "scene": {
    "background": "普通生活环境的简洁背景，不出现商品、广告布景或可复用的具体地点",
    "lighting": "柔和的普通自然光，有轻微现场明暗变化，不在额头、鼻梁和面颊制造油亮高光"
  },
  "composition": {
    "camera": "普通人像记录视角",
    "framing": "一张三视图参考图，三个视图大小接近且都能看清脸型、发型、肩部关系和体型比例；不做广告头像构图",
    "aspect_ratio": "3:4"
  },
  "style": {
    "finish": "普通人物参考照片，不做角色设定页、广告大片或精修人像",
    "color_and_retouching": "自然半哑光皮肤，保留皮肤纹理和光线变化，克制磨皮，不使用油亮高光或湿润妆面"
  },
  "constraints": {
    "must_keep": [],
    "avoid": ["商品展示", "广告模特姿势", "夸张表情", "影棚精修头像", "角色设定稿排版", "文字标注", "油腻高光", "塑料皮肤", "过度磨皮"]
  }
}
```

## 使用边界

需要跨图保持身份时，封面和后续配图可使用 `model.png`；每张图重新设计表情、视线、脸部朝向、身体状态和构图。封面只有在明确需要延续人物身份且适合作为身份依据时才补充使用。

如果用户明确要求同一地点或同一套衣服，可以把封面作为环境或穿搭参考单独说明；不要把它写成“复制封面人物”。
